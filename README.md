# 🏊 השחייה שלי

דשבורד אישי בעברית לאימוני השחייה שנמדדים בשעון Garmin vívoactive 4.
המערכת שואבת את הנתונים מ-Garmin Connect באופן אוטומטי, מתקנת בריכות "מפוצלות" (כשהשעון סופר בריכה נוספת בגלל עצירה או סידור משקפת), ומציגה הכול בדף אחד פשוט.

## מה יש בדשבורד
- **השחייה האחרונה**: מרחק אחרי תיקון, קצב ל-100 מ', זמן נטו וזמן כולל, מנוחות, דופק, קלוריות, SWOLF ותנועות לבריכה - עם השוואה לפעם הקודמת.
- **סטים ותיקון בריכות**: כל סט עם הבריכות שלו. בריכות קצרות מדי מסומנות ומאוחדות אוטומטית. אפשר לתקן ידנית עם + / − או בלחיצה "כל סט = 10".
- **תובנות** בעברית פשוטה, זמן באזורי דופק, וקלוריות במונחי אוכל.
- **מגמות**: קצב, מנוחות, זמן כולל, דופק ממוצע ושיא, SWOLF.
- **דקות אירוביות בשבוע** מול יעד 150 הדקות.
- **מסע הכולסטרול**: שבועות של עקביות, תזכורת לבדיקת דם חוזרת, ויומן תוצאות (LDL, HDL, טריגליצרידים).
- **דף עזר** למה ללחוץ בשעון.

## איך זה עובד
1. תהליך GitHub Actions (`.github/workflows/sync.yml`) רץ פעם ביום ב-21:07 (שעון ישראל בחורף), או בלחיצה על "משוך שחייה חדשה" בדשבורד.
2. הסקריפט `fetch/fetch_garmin.py` מתחבר לגרמין, שואב שחיות חדשות (כולל פירוט כל בריכה) ושומר אותן **מוצפנות** (AES-256) ב-`docs/data/activities.enc.json`.
3. אם יש שינוי (שחייה חדשה, תיקון ידני, בדיקת דם), `fetch/ai_coach.py` שולח את כל השחיות ל-Claude, שבודק את ספירת הבריכות וכותב פרשנות מילולית ויעדים לשחייה הבאה.
4. הדשבורד (`docs/`) מתפרסם ב-GitHub Pages ומפענח את הנתונים בדפדפן בעזרת הסיסמה שלך. בלי הסיסמה רואים רק קוד.

## התקנה (פעם אחת)
1. **Secrets** - בריפו: Settings ← Secrets and variables ← Actions ← New repository secret:
   - `DASHBOARD_PASSWORD` - סיסמה שתבחר לדשבורד.
   - `GARMIN_EMAIL` ו-`GARMIN_PASSWORD` - פרטי הכניסה לגרמין.
   - `ANTHROPIC_API_KEY` - מפתח API מ-console.anthropic.com (לפרשנות המילולית ולבדיקת הבריכות; כמה סנטים לכל שחייה).
   - (חלופה, אם יש אימות דו-שלבי) `GARMIN_TOKENS` - מריצים `python fetch/first_login.py` ומדביקים את הפלט.
2. **Pages** - Settings ← Pages ← Source: **GitHub Actions**.
3. **הרצה ראשונה** - Actions ← "סנכרון מגרמין ופרסום הדשבורד" ← Run workflow.
4. **כפתור המשיכה בדשבורד** (לא חובה) - יוצרים Fine-grained token ב-GitHub לריפו הזה בלבד, עם הרשאות Actions: Read and write ו-Contents: Read and write, ומדביקים אותו בהגדרות (⚙) בדשבורד. בלי טוקן, הכפתור פותח את דף ההרצה ב-GitHub.
